# Portfolio Project

This is a personal portfolio project built with Next.js, TypeScript, and Tailwind CSS. It showcases projects, skills, and contact information in a modern, responsive web application.

You can visit the live demo at [https://amrfayezz1-portfolio.vercel.app](https://amrfayezz1-portfolio.vercel.app).

## Features

- **Next.js 14** for server-side rendering and routing
- **TypeScript** for type safety
- **Tailwind CSS** for utility-first styling
- **Reusable UI components** (Accordion, Dialog, Carousel, etc.)
- **Contact form** with actions
- **Project gallery** with images and videos
- **Dark/light theme support**
- **Responsive design**

## Project Structure

```
app/           # Next.js app directory (pages, layouts, routes)
components/    # Reusable UI and custom components
hooks/         # Custom React hooks
lib/           # Utility functions
public/        # Static assets (images, videos)
styles/        # Global styles
```

## Getting Started

1. **Install dependencies**
   ```sh
   pnpm install
   ```
2. **Run the development server**
   ```sh
   pnpm dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the app.

## Customization

- Update your information, projects, and images in the respective folders.
- Modify or add components in `components/` as needed.

## Scripts

- `pnpm dev` – Start development server
- `pnpm build` – Build for production
- `pnpm start` – Start production server
